# เอกสารโครงการ

[กลับไปที่ README ภาษาไทย](../README.th.md) | [English documentation](README.md)

โฟลเดอร์นี้รวบรวมเอกสารทางเทคนิคและเอกสารสำหรับส่งผลงาน SakuraTH GeoIP2Route เข้าประกวด โดยสามารถเลือกอ่านตามวัตถุประสงค์ได้จากตารางต่อไปนี้

| เอกสาร | ใช้สำหรับ |
|---|---|
| [USER-GUIDE.th.md](USER-GUIDE.th.md) | คู่มือการใช้งานฉบับละเอียด คำอธิบายส่วนติดต่อผู้ใช้ และรายการภาพหน้าจอที่ควรบันทึก 14 ภาพ |
| [ALGORITHM.md](ALGORITHM.md) | สูตรคำนวณคะแนน หลักฐานจากการตรวจวัด HTTP ข้อจำกัดของการนำเข้า และข้อจำกัดของระบบ |
| [SUBMISSION.md](SUBMISSION.md) | ชื่อโครงการ คำอธิบายโดยย่อ หมายเหตุ และข้อความสำหรับแบบฟอร์มการประกวด |
| [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md) | รายการตรวจสอบก่อนเปิดให้บริการหรือส่งผลงานเข้าประกวด |
| [VALIDATION.md](VALIDATION.md) | รายการที่ตรวจสอบแล้ว และรายการที่ยังต้องตรวจสอบบนระบบจริง |
| [../CHANGELOG.md](../CHANGELOG.md) | ประวัติการเปลี่ยนแปลงแต่ละเวอร์ชัน |

## ลำดับการอ่านโดยย่อ

1. อ่าน [README ภาษาไทย](../README.th.md) เพื่อทำความเข้าใจระบบและวิธีเปิดใช้งาน
2. อ่าน [ALGORITHM.md](ALGORITHM.md) ก่อนอธิบายความหมายของคะแนน
3. ดำเนินการตาม [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md) ก่อนเผยแพร่เว็บไซต์ต่อสาธารณะ
4. ใช้ข้อความที่ผ่านการตรวจสอบจาก [SUBMISSION.md](SUBMISSION.md) ในแบบฟอร์มการประกวด
5. อ่าน [VALIDATION.md](VALIDATION.md) เพื่อแยกผลการทดสอบอัตโนมัติออกจากรายการที่ต้องตรวจสอบบนระบบจริง

## ขอบเขตของโครงการ

GeoIP2Route เปรียบเทียบข้อมูลตำแหน่ง IP และจัดอันดับเซิร์ฟเวอร์ ระบบมิได้ดำเนินการ Traceroute, ICMP Ping, ค้นหาเส้นทางแพ็กเก็ต, Failover, Load Balancing หรือตรวจวัดจากตัวแทนระยะไกล ระยะทางบนแผนที่เป็นค่าประมาณ ส่วนเวลา HTTP เป็นหลักฐานอีกประเภทหนึ่งที่ตรวจวัดจากเบราว์เซอร์ซึ่งเปิดแอป

## ข้อมูลสำคัญของรุ่นเผยแพร่

- รุ่นที่เตรียมเผยแพร่: `v1.8.0`
- Node.js: `20.19+` หรือ `22.12+`
- นำเข้ารายการที่ไม่ซ้ำกันได้สูงสุด 200 รายการ และรองรับไฟล์ขนาดไม่เกิน 1 MiB
- การตรวจวัดจากเบราว์เซอร์: ส่งคำขอ GET 3 ครั้ง ใช้ค่ามัธยฐานของเวลาจนได้รับส่วนหัวการตอบกลับที่สำเร็จ และกำหนดเวลาสิ้นสุด 4.5 วินาทีต่อครั้ง
- ชุดทดสอบอัตโนมัติ: การทดสอบ 45 รายการและการตรวจสอบโครงสร้าง
- ข้อจำกัดของฟังก์ชัน Netlify: ค้นหาข้อมูล 60 ครั้งต่อนาที และตรวจหา IP ปัจจุบัน 20 ครั้งต่อนาที ต่อ IP/โดเมน

ควรรักษาตัวเลขเหล่านี้ให้ตรงกับการทำงานจริง และปรับปรุงเอกสารหน้านี้เมื่อมีรุ่นใหม่
