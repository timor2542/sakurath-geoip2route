# คู่มือการใช้งาน

SakuraTH GeoIP2Route เป็นเครื่องมือบนเบราว์เซอร์สำหรับเปรียบเทียบตำแหน่ง IP และจัดอันดับเซิร์ฟเวอร์ด้วยข้อมูลจาก IP2Location

## เปิดใช้งาน

- [เปิดแอปออนไลน์](https://sakurath-geoip2route.netlify.app/)
- [ดูซอร์สโค้ดบน GitHub](https://github.com/timor2542/sakurath-geoip2route)

เมื่อเปิดแอป ระบบจะแสดงตำแหน่งตัวอย่าง 8 จุดเพื่อให้ทดลอง workflow หลักได้โดยไม่ต้องใช้ API key

![หน้าเริ่มต้น แผนที่ หมุด ปุ่มซูม และโหมดเปรียบเทียบ IP](guide-start.jpg)

## 1. เพิ่ม IP

ใช้ส่วน **ADD IPs TO THE LIST** หรือ **เพิ่ม IP ลงรายการ**:

- พิมพ์ Public IP หรือ Hostname หนึ่งรายการ แล้วกด `+`
- กด **Paste list** เพื่อวางรายการ โดยใส่หนึ่งรายการต่อหนึ่งบรรทัด
- กด **Import CSV** เพื่อเลือกไฟล์ที่มีคอลัมน์ `ip` หรือ `target` ระบบจะแสดงบทบาทของคอลัมน์ ตัวอย่างแถวแรก และจำนวนรายการที่ถูกต้อง/ไม่ถูกต้องก่อนนำเข้า

![ปุ่มเพิ่มรายการ IP และจัดการจุดบนแผนที่](guide-import-csv.jpg)

ระบบจะส่งคำขอ Lookup หลังจากยืนยันการนำเข้าเท่านั้น และจะตัดรายการซ้ำให้อัตโนมัติ

## 2. เปรียบเทียบสองจุด

1. เลือกแท็บ **IP Compare**
2. คลิกหมุดบนแผนที่หรือแถวในส่วน **MAP POINTS** สองรายการ จุดแรกจะเป็น A และจุดที่สองจะเป็น B
3. ดูผลทางขวา ได้แก่ ระยะทางบนผิวโลก ประเทศ ภูมิภาค/เมือง ISP, ASN, ประเภทการใช้งาน IP และเขตเวลา

เส้นบนแผนที่แสดงความสัมพันธ์ทางภูมิศาสตร์ ไม่ใช่เส้นทาง Traceroute

## 3. จัดอันดับเซิร์ฟเวอร์

![โหมดจัดอันดับเซิร์ฟเวอร์](guide-server-ranking.jpg)

1. เลือกแท็บ **Server Ranking**
2. เลือก IP อ้างอิงทางภูมิศาสตร์
3. เลือก **Geographic fit** เพื่อจัดอันดับจากระยะทางและความเหมาะสมของเครือข่าย
4. หากต้องการวัดจริง ให้เพิ่ม **Probe URL** แบบ HTTPS ที่เปิด CORS แล้วกดวัดจากเบราว์เซอร์

คะแนน Geo fit ใช้ระยะทาง 80% และความเหมาะสมของเครือข่าย 20% ส่วน HTTP ranking ใช้เวลาตอบสนองที่วัดจากเบราว์เซอร์เป็นสัญญาณแยกต่างหาก

## 4. ใช้แผนที่

- ปุ่ม `+` และ `−` ใช้ซูมเข้า/ออก
- ปุ่มมุมทั้งสี่ใช้จัดแผนที่ให้เห็นทุกจุด
- เส้น Grid และมาตรวัดมุมล่างขวาแสดงสัดส่วนภูมิศาสตร์ปัจจุบัน
- คลิกหมุดเพื่อดูเมือง IP และข้อมูลเครือข่าย

## 5. ล้างหรือลบจุด

- **Clear A/B selection** ล้างเฉพาะการเลือก A/B แต่เก็บ IP ทั้งหมดไว้
- ไอคอนถังขยะท้ายแถว ลบเฉพาะ IP รายการนั้น
- **Delete all** ลบทุกจุดหลังจากยืนยัน

## 6. เปิดคำแนะนำในแอป

![หน้าต่างคำแนะนำการใช้งาน](guide-help.jpg)

กดปุ่ม `?` บริเวณหัวแอปเพื่อดูคำอธิบายสั้น ๆ เกี่ยวกับการเพิ่ม IP การเปรียบเทียบ และการจัดอันดับ

## ข้อควรรู้

- ตำแหน่ง IP เป็นค่าประมาณ ไม่ใช่ GPS
- HTTP timing วัดจากเบราว์เซอร์ที่เปิดแอป ไม่ใช่ ICMP Ping หรือ Traceroute
- การ Lookup กับ IP2Location แบบ Live ต้องใช้ API key ส่วนข้อมูลตัวอย่างใช้สำหรับทดลอง UI ได้ทันที
