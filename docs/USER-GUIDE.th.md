# คู่มือการใช้งาน SakuraTH GeoIP2Route

[English](USER-GUIDE.md) | [เอกสารโครงการ](README.th.md)

คู่มือนี้อธิบายขั้นตอนหลักของ SakuraTH GeoIP2Route ภาพประกอบบันทึกจากรุ่น `v1.8.0` ข้อมูล IP เวลา และคะแนนจากการใช้งานจริงอาจแตกต่างจากภาพ

- เว็บแอปพลิเคชัน: <https://sakurath-geoip2route.netlify.app/>.
- ที่เก็บซอร์สโค้ด: <https://github.com/timor2542/sakurath-geoip2route>.

## 1. วัตถุประสงค์ของแอปพลิเคชัน

SakuraTH GeoIP2Route มีโหมดการทำงานหลัก 2 โหมด ดังนี้

- **เปรียบเทียบ IP (IP Compare)** ใช้เปรียบเทียบตำแหน่ง IP สองจุด ซึ่งกำหนดเป็น A และ B พร้อมแสดงระยะทางโดยตรงบนแผนที่ ตำแหน่ง และข้อมูลเครือข่าย
- **จัดอันดับเซิร์ฟเวอร์ (Server Ranking)** ใช้ IP หนึ่งรายการเป็นตำแหน่งอ้างอิง (`SRC`) แล้วจัดอันดับจุดอื่นเป็นเซิร์ฟเวอร์ที่เป็นตัวเลือก โดยใช้ความเหมาะสมเชิงภูมิศาสตร์หรือเวลาตอบสนอง HTTP ที่ตรวจวัดจากเบราว์เซอร์

แอปพลิเคชันใช้ผลลัพธ์จาก IP2Location เป็นหลักฐานด้านตำแหน่งและเครือข่าย ระบบไม่ได้ทำ Traceroute, ICMP Ping, การเลือกเส้นทางอัตโนมัติ, Failover หรือ Load Balancing เส้นบนแผนที่ใช้เชื่อมตำแหน่งเท่านั้น มิใช่เส้นทางของแพ็กเก็ต

## 2. ส่วนประกอบของพื้นที่ทำงาน

![พื้นที่ทำงานบนเดสก์ท็อป ประกอบด้วยแผงควบคุม แผนที่ บันทึกกิจกรรม และแผงเปรียบเทียบ](img/01.png)

*ภาพที่ 1 พื้นที่ทำงานของโหมดเปรียบเทียบ IP บนหน้าจอเดสก์ท็อป*

พื้นที่ทำงานแบ่งเป็น 4 ส่วนหลัก

| ส่วน | หน้าที่ |
|---|---|
| ส่วนหัว | เปลี่ยนโหมด ตรวจสอบเวลาอ้างอิง โหลดหน้าใหม่ เปิดวิธีใช้ เปลี่ยนภาษา และเลือกธีม |
| แผงด้านซ้าย | เพิ่ม อัปเดต นำเข้า เลือก หรือลบจุด IP |
| ส่วนกลาง | แสดงแผนที่ เส้นเชื่อมเชิงภูมิศาสตร์ ตารางกริด มาตราส่วน และบันทึกกิจกรรม |
| แผงด้านขวา | แสดงผลการเปรียบเทียบหรือผลการจัดอันดับ |

ความหมายของสัญลักษณ์บนแผนที่และในรายการ

| สัญลักษณ์ | ความหมาย |
|---|---|
| `A` สีชมพู | จุดแรกในโหมดเปรียบเทียบ IP |
| `B` สีเหลือง | จุดที่สองในโหมดเปรียบเทียบ IP |
| `SRC` สีเขียว | ตำแหน่งอ้างอิงในโหมดจัดอันดับเซิร์ฟเวอร์ |
| หมุดสีเทาพร้อมตัวเลข | จุด IP อื่น หรือลำดับปัจจุบัน |
| `LIVE` | ข้อมูลที่ได้จากการค้นหาจริง |
| `SAMPLE` | ข้อมูลตัวอย่างที่มาพร้อมกับแอปพลิเคชัน |

## 3. เมนูทางลัดและการตั้งค่าการแสดงผล

![เมนู Sections ที่ขยายอยู่ข้างแผงควบคุมหลัก](img/02.png)

*ภาพที่ 2 ขยายแถบ Sections เพื่ออ่านชื่อเมนูทางลัดแต่ละรายการ*

แถบแนวตั้งด้านซ้ายสุดใช้เข้าถึงหัวข้อต่าง ๆ ในแผงควบคุมได้อย่างรวดเร็ว กดไอคอนเมนูรายการแรกเพื่อแสดงหรือซ่อนชื่อเมนู ไอคอนที่เหลือจะเลื่อนไปยังหัวข้อต่อไปนี้

1. เพิ่ม IP ปัจจุบัน
2. อัปเดตรายการจาก IP2Location
3. เพิ่ม IP ลงในรายการ
4. จุดบนแผนที่
5. การสาธิตและตัวอย่าง

เมนูที่กำลังใช้งานจะมีสีเน้น การเลือกเมนูทางลัดจะเลื่อนเฉพาะแผงด้านซ้าย โดยไม่เปลี่ยนจุด IP หรือผลลัพธ์ปัจจุบัน

ส่วนควบคุมอื่นในส่วนหัวมีหน้าที่ดังนี้

- **IP Compare / Server Ranking** ใช้เปลี่ยนโหมดการทำงาน
- **Refresh** ใช้โหลดแอปพลิเคชันใหม่ ซึ่งต่างจาก **Update list from IP2Location** ที่ใช้ค้นหาข้อมูลของจุดทั้งหมดอีกครั้ง
- **EN / TH** ใช้เปลี่ยนภาษาของส่วนติดต่อผู้ใช้
- ไอคอนดวงอาทิตย์ ดวงจันทร์ และวงกลมครึ่งทึบ ใช้เลือกธีมสว่าง ธีมมืด และธีมอัตโนมัติ
- นาฬิกาจะอ้างอิงจุด A ในโหมดเปรียบเทียบ IP และอ้างอิง `SRC` ในโหมดจัดอันดับ หากยังไม่มีการเลือก ระบบจะใช้จุดแรกหรือเวลาของอุปกรณ์

## 4. การจัดทำรายการ IP

### 4.1 เพิ่ม IP สาธารณะของการเชื่อมต่อปัจจุบัน

กด **Add current IP** แอปพลิเคชันจะตรวจหา IP สาธารณะของการเชื่อมต่อ ขอข้อมูลที่เกี่ยวข้อง แล้วเพิ่มหรืออัปเดตจุดที่ตรงกัน ผลลัพธ์จะถูกเลือกเป็น A ในโหมดเปรียบเทียบ IP และเป็น `SRC` ในโหมดจัดอันดับเซิร์ฟเวอร์

![การค้นหา IP ปัจจุบันกำลังดำเนินการ โดยปิดใช้งานส่วนควบคุมชั่วคราวและแสดงข้อความ WAIT](img/13.png)

*ภาพที่ 3 ส่วนควบคุมจะถูกปิดใช้งานชั่วคราวระหว่างการค้นหา IP ปัจจุบัน*

ควรรอข้อความสำเร็จหรือข้อความแจ้งข้อผิดพลาดก่อนเริ่มค้นหารายการอื่น หากคำขอล้มเหลว แอปพลิเคชันจะแจ้งข้อผิดพลาดและจะไม่สร้างข้อมูลตำแหน่งขึ้นเอง

### 4.2 เพิ่ม IP สาธารณะหรือชื่อโฮสต์หนึ่งรายการ

1. ไปที่หัวข้อ **ADD IPs TO THE LIST**
2. ป้อน IPv4 สาธารณะ, IPv6 สาธารณะ หรือชื่อโฮสต์
3. กด `+` หรือกด Enter
4. รอจนกว่ารายการใหม่หรือรายการที่อัปเดตแล้วจะปรากฏในรายการและบนแผนที่

ตัวอย่างข้อมูลที่ป้อนได้ ได้แก่ `8.8.8.8`, `2606:4700:4700::1111` และ `example.com`

แอปพลิเคชันจะไม่ยอมรับ IP ภายใน IP ส่วนตัว และ IP ที่สงวนไว้ หากชื่อโฮสต์สองชื่อชี้ไปยัง IP เดียวกัน ระบบจะเก็บเป็นหนึ่งจุดและอัปเดตข้อมูลของจุดเดิม

### 4.3 วางเป้าหมายหลายรายการ

1. กด **Paste list**
2. ป้อน IP หรือชื่อโฮสต์หนึ่งรายการต่อหนึ่งบรรทัด
3. ตรวจสอบจำนวนรายการเดิมและรายการที่จะนำเข้า
4. เลือกว่าจะเก็บรายการเดิมหรือแทนที่รายการเดิม
5. เริ่มการค้นหา

บรรทัดที่ขึ้นต้นด้วย `#` จะถือเป็นหมายเหตุ ระบบจะรวมเป้าหมายที่ซ้ำกันก่อนเริ่มค้นหา

```text
8.8.8.8
1.1.1.1
example.com
2606:4700:4700::1111
```

### 4.4 อัปเดตทุกจุด

กด **Update list from IP2Location** เพื่อขอข้อมูลล่าสุดของจุดทั้งหมด ปุ่มจะแสดงความคืบหน้า และบันทึกกิจกรรมจะแสดงผลของแต่ละรายการ

![รายการที่อัปเดตแล้วแสดงป้าย LIVE ชื่อผู้ให้บริการ และข้อความค้นหาสำเร็จ](img/10.png)

*ภาพที่ 4 เมื่ออัปเดตสำเร็จ แถวจะแสดงป้าย LIVE และชื่อผู้ให้บริการเครือข่ายที่ได้รับกลับมา*

การอัปเดตจะคงรายการที่กำลังใช้งานไว้ หากรายการใดค้นหาไม่สำเร็จ รายการนั้นจะยังคงปรากฏอยู่ เพื่อไม่ให้ความล้มเหลวของคำขอหนึ่งรายการลบข้อมูลทั้งหมด

## 5. การนำเข้าไฟล์ CSV

### 5.1 เลือกไฟล์

กด **Import CSV** แล้วเลือกไฟล์ `.csv` หรือ `.txt` จากอุปกรณ์

![หน้าต่างเลือกไฟล์แสดงตัวอย่าง CSV ในโฟลเดอร์ sample-data](img/17.png)

*ภาพที่ 5 ที่เก็บโครงการมีไฟล์ CSV ในโฟลเดอร์ `sample-data` สำหรับทดลองขั้นตอนการนำเข้า*

ไฟล์รูปแบบขั้นต่ำต้องมีคอลัมน์เป้าหมายหนึ่งคอลัมน์

```csv
ip
8.8.8.8
1.1.1.1
```

ชื่อหัวคอลัมน์เป้าหมายที่รองรับ ได้แก่ `target`, `ip`, `ip_address`, `address`, `hostname` และ `host` โดยสามารถเรียงลำดับคอลัมน์ต่างกันได้

สามารถเพิ่ม URL แบบ HTTPS สำหรับการตรวจวัดในโหมด Browser HTTP ได้

```csv
target,probe_url
dns.google,https://dns.google/resolve?name=example.com&type=A
```

โฮสต์ของ Probe URL ต้องตรงกับเป้าหมายในแถวเดียวกัน คอลัมน์ตำแหน่งอื่นจะแสดงเป็นข้อมูลอ้างอิงเท่านั้น ส่วนตำแหน่งที่ใช้บนแผนที่จะมาจากการค้นหาจริง

### 5.2 ตรวจสอบโครงสร้าง

![หน้าต่างตรวจสอบ CSV แสดงคอลัมน์ที่ตรวจพบ จำนวนแถว และตัวอย่างแถวแรก](img/18.png)

*ภาพที่ 6 ระบบยังไม่เริ่มค้นหา IP ขณะที่เบราว์เซอร์กำลังตรวจสอบไฟล์*

ก่อนนำเข้า ควรตรวจสอบรายการต่อไปนี้

- ชื่อไฟล์และข้อความ CSV ต้นฉบับ
- จำนวน Rows, Valid และ Need attention
- คอลัมน์ Target และ Probe ที่ระบบตรวจพบ
- แถวแรกในส่วนตัวอย่าง
- ข้อความระบุแถวที่ผิด หากพบข้อมูลไม่ถูกต้อง

ระบบสามารถตรวจพบหัวคอลัมน์ที่ขาดหรือซ้ำ เป้าหมายที่ไม่ถูกต้อง Probe URL ที่ไม่ตรงกับเป้าหมาย ช่องข้อมูลส่วนเกิน หรือเครื่องหมายอัญประกาศที่ปิดไม่ครบ หากมีแถวที่ต้องแก้ไข ให้แก้ไฟล์แล้วเลือกไฟล์ใหม่

### 5.3 เลือกเก็บหรือแทนที่รายการปัจจุบัน

![ตัวเลือกการนำเข้า CSV สำหรับเก็บหรือแทนที่รายการปัจจุบัน](img/20.png)

*ภาพที่ 7 ตัวเลือก Keep current list เหมาะสำหรับการนำเข้าทั่วไป*

- **Keep current list** เพิ่มแถวที่สำเร็จและรวมรายการซ้ำเข้ากับรายการปัจจุบัน
- **Replace current list** ลบรายการเดิมหลังจากไฟล์ใหม่ให้ผลการค้นหาที่สำเร็จแล้วเท่านั้น หากค้นหาไม่สำเร็จทุกรายการ ระบบจะเก็บรายการเดิมไว้

กด **Locate and add all** เพื่อเริ่มดำเนินการ หนึ่งครั้งสามารถนำเข้าเป้าหมายที่ไม่ซ้ำกันได้สูงสุด 200 รายการ และไฟล์ต้องมีขนาดไม่เกิน 1 MiB

## 6. การเปรียบเทียบ IP สองจุด

เลือก **IP Compare** แล้วเลือกหมุดบนแผนที่หรือแถวในหัวข้อ **MAP POINTS**

![โหมดเปรียบเทียบ IP ที่เลือกเฉพาะจุด A และรอให้เลือกจุด B](img/05.png)

*ภาพที่ 8 จุดที่เลือกเป็นรายการแรกจะเป็น A และแผงผลลัพธ์จะรอให้เลือก B*

เลือกจุดอื่นเพื่อกำหนดเป็น B หากเลือกจุดที่สาม จุดดังกล่าวจะแทนที่ B โดย A ยังคงเดิม หากเลือกจุด A หรือ B ที่กำลังใช้งานอีกครั้ง ระบบจะยกเลิกการเลือกจุดนั้น

![ผลการเปรียบเทียบกรุงเทพฯ และ Mountain View พร้อมเส้นเชื่อมและระยะทาง](img/08.png)

*ภาพที่ 9 เมื่อเลือก A และ B ครบแล้ว แผนที่จะเชื่อมสองจุดและแผงผลลัพธ์จะแสดงข้อมูลเปรียบเทียบ*

ควรอ่านผลลัพธ์ตามลำดับต่อไปนี้

1. ตรวจสอบชื่อ หมายเลข IP และป้าย A/B
2. อ่านระยะทางแบบวงกลมใหญ่ ซึ่งเป็นระยะทางโดยตรงเชิงภูมิศาสตร์ มิใช่ค่าหน่วงของเครือข่าย
3. เปรียบเทียบประเทศ ภูมิภาคและเมือง ISP, ASN, ประเภทการใช้งาน IP และเขตเวลา
4. ใช้ตัวบ่งชี้เหมือน/ต่างเพื่อตรวจหาคุณสมบัติเครือข่ายที่ตรงกันอย่างรวดเร็ว

ตำแหน่ง IP เป็นค่าประมาณ ที่อยู่แบบ Anycast หรือ CDN อาจแสดงตำแหน่งต่างกันเมื่อเข้าถึงจากเครือข่ายอื่น

## 7. การจัดอันดับเซิร์ฟเวอร์

เลือก **Server Ranking** แล้วเลือก **Geographic reference IP** จุดที่เลือกจะเปลี่ยนเป็น `SRC` และจะไม่ถูกนำไปจัดอันดับเป็นตัวเลือก

![หน้าจัดอันดับเซิร์ฟเวอร์ แสดงหมุด SRC เส้นเชื่อมผู้สมัคร และรายการคะแนนเชิงภูมิศาสตร์](img/23.png)

*ภาพที่ 10 การจัดอันดับเชิงภูมิศาสตร์เปรียบเทียบตัวเลือกทุกจุดกับตำแหน่งอ้างอิง*

### ความเหมาะสมเชิงภูมิศาสตร์

คะแนนความเหมาะสมเชิงภูมิศาสตร์ประกอบด้วยระยะทางและค่าความเหมาะสมของประเภทเครือข่าย โดยทั่วไปตัวเลือกที่อยู่ใกล้กว่าจะได้คะแนนระยะทางสูงกว่า ผลลัพธ์เป็นคะแนนเปรียบเทียบตั้งแต่ 0 ถึง 100 มิใช่ค่าร้อยละหรือคำรับรองการให้บริการ

```text
distance_score = clamp(100 - distance_km / 200.37, 0, 100)
Geographic fit = 80% distance_score + 20% network_preference
```

### การตรวจวัด HTTP จากเบราว์เซอร์

เลือก **Browser HTTP** เพื่อจัดอันดับเฉพาะตัวเลือกที่กำหนด HTTPS Probe ไว้ การตรวจวัด HTTP จะเริ่มจากเบราว์เซอร์ที่เปิดแอปพลิเคชันเสมอ การเปลี่ยน `SRC` ไม่ได้เปลี่ยนต้นทางของการตรวจวัด

ดำเนินการกับตัวเลือกแต่ละรายการดังนี้

1. เลือกแถวของตัวเลือก
2. ป้อน Probe URL แบบ HTTPS ที่อนุญาตคำขอข้ามต้นทาง
3. บันทึกและตรวจวัดตัวเลือก หรือสั่งตรวจวัด Probe ที่กำหนดไว้ทั้งหมด
4. อ่านค่ามัธยฐานของเวลาตอบสนองที่สำเร็จและจำนวนครั้งที่สำเร็จ

แอปพลิเคชันส่งคำขอ 3 ครั้งตามลำดับ และยุติคำขอแต่ละครั้งเมื่อครบ 4.5 วินาที ระบบใช้ค่ามัธยฐานของผลที่สำเร็จ การตรวจวัดจากเบราว์เซอร์ที่ล้มเหลวมิได้ยืนยันว่าเซิร์ฟเวอร์ออฟไลน์ เพราะ CORS, TLS, การเปลี่ยนเส้นทาง หรือการเชื่อมต่อภายในเครื่องอาจเป็นสาเหตุได้

รายละเอียดสูตรทั้งหมดอยู่ใน [ALGORITHM.th.md](ALGORITHM.th.md)

## 8. การใช้แผนที่

- กด `+` หรือ `−` เพื่อซูมเข้าและออก
- กดไอคอนกรอบสี่มุมเพื่อจัดมุมมองให้ครอบคลุมทุกจุด
- ลากแผนที่เพื่อเลื่อนมุมมอง
- กดหมุดเพื่อดูหรือเลือกจุดนั้น
- ใช้ตารางกริดรูปสี่เหลี่ยมเพื่อช่วยเปรียบเทียบสัดส่วนบนแผนที่
- อ่านมาตราส่วนด้านล่างขวาเพื่อดูระยะทางโดยประมาณของหนึ่งช่องกริด ค่าในมาตราส่วนจะเปลี่ยนตามระดับการซูม

คำอธิบายสัญลักษณ์บนแผนที่จะเปลี่ยนตามโหมด เส้นในโหมดเปรียบเทียบเชื่อม A กับ B ส่วนเส้นในโหมดจัดอันดับเชื่อม `SRC` กับตัวเลือก เส้นทั้งสองประเภทไม่แสดงจุดผ่านของเครือข่าย

## 9. การอ่านบันทึกกิจกรรม

บันทึกกิจกรรมจะแสดงการทำงานในเบราว์เซอร์รอบปัจจุบัน ป้ายที่พบบ่อยมีดังนี้

- `[INFO]` แสดงการเปลี่ยนสถานะทั่วไป
- `[WAIT]` แสดงงานที่กำลังดำเนินการ
- `[OK]` แสดงงานที่เสร็จสมบูรณ์
- `[ERROR]` แสดงงานที่ดำเนินการไม่สำเร็จ
- `[DEMO]` แสดงกิจกรรมจากข้อมูลจำลอง

กดลูกศรเพื่อเปิดหรือย่อแผงบันทึกกิจกรรม ปุ่ม **Clear** จะลบเฉพาะข้อความบันทึก และไม่ลบจุด IP

## 10. การส่งออกผลการจัดอันดับ

โหมดจัดอันดับเซิร์ฟเวอร์สามารถส่งออก JSON สำหรับข้อมูลเชิงโครงสร้างอย่างครบถ้วน หรือ CSV สำหรับวิเคราะห์ในตารางคำนวณ ข้อมูลส่งออกประกอบด้วยลำดับ เป้าหมาย ตำแหน่ง วิธีคำนวณ คะแนน ระยะทาง หลักฐาน HTTP (ถ้ามี) ประเภทเครือข่าย และส่วนประกอบของคะแนน

ก่อนเผยแพร่ไฟล์ส่งออก ควรตรวจสอบ IP อ้างอิงและ Probe URL เนื่องจากข้อมูลดังกล่าวอาจระบุการเชื่อมต่อหรือระบบทดสอบภายในของผู้ใช้

## 11. การล้างหรือการลบข้อมูล

- **Clear A/B selection** เก็บจุดทั้งหมดไว้และยกเลิกเฉพาะการเลือกเปรียบเทียบ
- ไอคอนถังขยะในแต่ละแถวจะแสดงการยืนยันก่อนลบหนึ่งจุด
- **Delete all** จะแสดงการยืนยันก่อนลบทุกจุด รวมทั้งล้าง A/B, `SRC`, เซิร์ฟเวอร์ที่เลือก และงาน Probe ที่ยังไม่เสร็จ
- **Clear** ในบันทึกกิจกรรมจะลบเฉพาะข้อความบันทึก
- การโหลดหน้าใหม่จะรีเซ็ตรายการที่กำลังใช้งานและผลตรวจวัดจากเบราว์เซอร์

## 12. การใช้งานบนมือถือและด้วยแป้นพิมพ์

บนหน้าจอแคบ แผนที่จะปรากฏก่อน และแผงอื่นจะแสดงต่อเนื่องลงมาด้านล่าง หากแผงใดมีแถบเลื่อนของตนเอง ให้เลื่อนภายในแผงนั้น

- ปุ่ม Tab ใช้เลื่อนจุดโฟกัสผ่านส่วนควบคุมต่าง ๆ
- ปุ่ม Enter ใช้ส่งแบบฟอร์มเพิ่ม IP
- ปุ่ม Escape ใช้ปิดหน้าต่างโต้ตอบที่ไม่ได้กำลังประมวลผล
- จุดโฟกัสจะอยู่ภายในหน้าต่างโต้ตอบจนกว่าจะปิด
- ส่วนติดต่อผู้ใช้จะปฏิบัติตามการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์

## 13. ลำดับการใช้งานโดยย่อ

สำหรับการเปรียบเทียบทั่วไป ให้ดำเนินการตามลำดับดังนี้

1. เพิ่มหรือนำเข้าเป้าหมายสาธารณะที่ต้องการ
2. อัปเดตรายการเมื่อต้องการข้อมูลล่าสุดจาก IP2Location
3. เลือก A และ B ในโหมดเปรียบเทียบ IP
4. อ่านระยะทางและข้อมูลเครือข่าย
5. เปิดโหมดจัดอันดับเซิร์ฟเวอร์และเลือก `SRC` เมื่อต้องการจัดอันดับตัวเลือก
6. ใช้ความเหมาะสมเชิงภูมิศาสตร์ หรือกำหนด HTTPS Probe ที่ถูกต้องก่อนใช้ Browser HTTP
7. ส่งออกและตรวจสอบผลลัพธ์ก่อนเผยแพร่

ตำแหน่ง IP ระยะทางเชิงภูมิศาสตร์ และเวลาตอบสนอง HTTP จากเบราว์เซอร์เป็นหลักฐานคนละประเภท ควรพิจารณาร่วมกัน และไม่ควรอธิบายข้อมูลประเภทใดประเภทหนึ่งว่าเป็นเส้นทางจริงของแพ็กเก็ต
