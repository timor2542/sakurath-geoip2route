# วิธีการจัดอันดับและหลักฐานประกอบ — v1.8.0

[English](ALGORITHM.md) | ภาษาไทย

## ระยะทางเชิงภูมิศาสตร์

IP Compare และ Server Ranking ใช้สูตร Haversine โดยกำหนดรัศมีโลกเป็น 6,371 กิโลเมตร โค้ดจะจำกัดค่าระหว่างการคำนวณให้อยู่ในช่วง 0 ถึง 1 เพื่อป้องกันความคลาดเคลื่อนจากการปัดเศษสำหรับจุดที่อยู่ตรงข้ามกันบนโลก แอปจะปฏิเสธพิกัดที่ขาดหายหรือไม่ถูกต้อง แทนการกำหนดตำแหน่งเป็น (0,0)

ผลลัพธ์เป็นระยะทางโดยประมาณระหว่างตำแหน่ง IP สองตำแหน่ง มิใช่ความยาวของเส้นทางเครือข่าย

## วิธีจัดอันดับสองรูปแบบ

ส่วนที่ใช้คำนวณ: `src/utils/ranking.js`

```text
distance_score = clamp(100 - distance_km / 200.37, 0, 100)
http_score     = clamp(100 - median_successful_http_ms / 4, 0, 100)

network preference:
  DCH or CDN = 100
  ISP        = 82
  MOB        = 70
  other/unknown = 76

Geographic fit = 0.8 × distance_score + 0.2 × network_preference
Browser HTTP  = 0.8 × http_score     + 0.2 × network_preference
```

ค่าประเภทเครือข่ายและขอบเขตคะแนนเป็นค่าที่โครงการกำหนด มิใช่ผลการพยากรณ์ที่ผ่านการพิสูจน์ด้วยงานวิจัย ประเภทเครือข่ายที่ไม่ทราบจะได้รับค่ากลาง โดยแอปจะไม่คาดเดาประเภทที่แท้จริง ประเภทเครือข่ายอาจมีผลต่อคะแนนมากกว่าความแตกต่างเพียงเล็กน้อยของระยะทางหรือเวลา ผู้ชนะคือเซิร์ฟเวอร์ที่มีคะแนนรวมสูงสุด จึงอาจมิใช่เซิร์ฟเวอร์ที่ใกล้ที่สุดหรือมีเวลา HTTP ต่ำที่สุดเสมอไป

คะแนนมีค่าตั้งแต่ 0 ถึง 100 แต่มิใช่ค่าร้อยละ แอปจะแสดงองค์ประกอบถ่วงน้ำหนักของคะแนนและส่วนต่างจากเซิร์ฟเวอร์ลำดับถัดไป หากคะแนนเท่ากัน แอปจะใช้รหัสภายในที่คงที่เพื่อรักษาลำดับ เซิร์ฟเวอร์ที่ยังไม่มีผลการตรวจวัดจะยังปรากฏในรายการ แต่จะไม่มีคะแนนและอันดับ

แอปจะไม่นำ IP อ้างอิงเชิงภูมิศาสตร์มารวมในรายชื่อเซิร์ฟเวอร์ โดยใช้ตำแหน่งดังกล่าวเพื่อคำนวณระยะทางเท่านั้น **การตรวจวัด Browser HTTP มิได้เริ่มจาก IP อ้างอิงที่เลือก** แต่เริ่มจากเบราว์เซอร์ของผู้ใช้ การเปลี่ยน IP อ้างอิงจึงไม่ทำให้คะแนน HTTP ของเซิร์ฟเวอร์เปลี่ยนแปลง

## การตรวจวัด Browser HTTP

ส่วนที่ใช้ตรวจวัด: `src/services/probe.js`

- แอปส่งคำขอ GET จำนวนสามครั้งตามลำดับ โดยจับเวลาตั้งแต่เริ่ม `fetch` จนได้รับส่วนหัวของการตอบกลับ
- ระบบใช้ค่ามัธยฐานของการตรวจวัดที่สำเร็จ หากมีข้อมูลจำนวนคู่ จะใช้ค่ากึ่งกลางระหว่างข้อมูลสองค่าที่อยู่ตรงกลาง
- ระบบตรวจวัด URL ของเซิร์ฟเวอร์พร้อมกันไม่เกินสองรายการ
- คำขอแต่ละครั้งจะยุติเมื่อครบ 4.5 วินาที
- URL ต้องใช้ HTTPS และชื่อโฮสต์หรือ IP ต้องตรงกับเซิร์ฟเวอร์ ระบบไม่อนุญาตพอร์ตที่กำหนดเอง ข้อมูลเข้าสู่ระบบ หรือส่วน Fragment ของ URL
- คำขอใช้ CORS โดยไม่ส่งข้อมูลเข้าสู่ระบบของเบราว์เซอร์หรือ Referrer ไม่ติดตาม Redirect และไม่ใช้ผลลัพธ์เดิมจากแคช
- ระบบจะนับเฉพาะการตอบกลับรหัส 2xx ที่เบราว์เซอร์อนุญาตให้อ่าน การตอบกลับแบบ Opaque และสถานะศูนย์จะไม่นับว่าสำเร็จ
- แอปยกเลิกการรับเนื้อหาการตอบกลับ เนื่องจากมิได้ตรวจวัดความเร็วในการดาวน์โหลด
- หากการตรวจวัดทั้งหมดล้มเหลว เซิร์ฟเวอร์จะไม่มีค่ามัธยฐานและอันดับ แอปจะไม่สรุปว่าเซิร์ฟเวอร์ออฟไลน์
- หากสำเร็จเพียงบางครั้ง ค่ามัธยฐานจะคำนวณจากผลที่สำเร็จเท่านั้น และแอปจะแสดงจำนวนครั้งที่สำเร็จตามจริง

การตรวจวัดนี้มิใช่ ICMP Ping การทดสอบความเร็วดาวน์โหลด หรือการตรวจวัดจากประเทศอื่น ผลลัพธ์อาจรวมเวลาสร้างการเชื่อมต่อ การประมวลผลของเซิร์ฟเวอร์ งานของเบราว์เซอร์ Service Worker ความเปลี่ยนแปลงของเครือข่าย และการเชื่อมต่อที่นำกลับมาใช้ใหม่ เพื่อให้เปรียบเทียบได้อย่างเหมาะสม ควรใช้ Endpoint ขนาดเล็กที่มีลักษณะใกล้เคียงกันและตรวจวัดซ้ำ

ชื่อโฮสต์อาจชี้ไปยัง IP ที่แตกต่างกันระหว่างเซิร์ฟเวอร์ของแอปกับเบราว์เซอร์ ซึ่งพบได้ทั่วไปในบริการ CDN และ Anycast การตรวจสอบชื่อโฮสต์ช่วยลดความเสี่ยงในการตรวจวัดผิดเซิร์ฟเวอร์ แต่ไม่สามารถยืนยันได้ว่าเป็นการตรวจวัดตรงไปยัง IP เดียว แอปจะป้องกัน IP ภายในและ IP สงวนที่ป้อนเป็นเป้าหมาย อย่างไรก็ตาม การตรวจสอบฝั่งเบราว์เซอร์นี้ไม่ครอบคลุม DNS Rebinding หรือการเปลี่ยนแปลงชื่อโฮสต์ที่เป็นไปได้ทั้งหมด

## การค้นหา การนำเข้า และการส่งออก

- เซิร์ฟเวอร์ใช้คีย์ IP2Location เพื่อค้นหาข้อมูล IP สาธารณะและชื่อโฮสต์
- แอปค้นหาข้อมูลพร้อมกันไม่เกินสามรายการ การนำเข้าแต่ละครั้งรองรับเป้าหมายที่ไม่ซ้ำสูงสุด 200 รายการ และไฟล์ขนาดไม่เกิน 1 MiB
- แอปจะรวมรายการที่แปลงไปยัง IP เดียวกัน การรีเฟรชจะรวมผลลัพธ์เข้ากับรายการปัจจุบัน และจะไม่นำจุดที่ผู้ใช้ลบระหว่างการรีเฟรชกลับมา
- แอปไม่ค้นหาเส้นทางแพ็กเก็ตและไม่สร้าง GeoJSON ไฟล์ JSON และ CSV ที่ส่งออกจะบันทึกหลักฐานการจัดอันดับ
- ข้อมูลส่งออกประกอบด้วยวิธีให้คะแนน สูตร ตำแหน่งอ้างอิง จุดเริ่มต้นการตรวจวัด ผลที่สำเร็จ และเวลาตรวจวัด
- การส่งออก CSV จะทำให้ข้อความที่มีรูปแบบเหมือนสูตรสเปรดชีตมีความปลอดภัยก่อนบันทึกไฟล์
- ผลการตรวจวัดและรายการที่กำลังใช้งานจะเริ่มต้นใหม่เมื่อโหลดหน้าเว็บใหม่ แอปมิได้อ้างว่าเก็บชุดข้อมูลอย่างถาวร

## ข้อจำกัดที่ทราบ

คะแนนมีไว้เพื่อช่วยเปรียบเทียบเซิร์ฟเวอร์ และไม่ควรใช้ตัดสินใจกำหนดเส้นทางในระบบจริงโดยลำพัง คะแนนไม่สามารถยืนยันระยะเวลาพร้อมใช้งาน ความถูกต้องของแอป คุณภาพการเชื่อมต่อ สถานที่จัดเก็บข้อมูล หรือการปฏิบัติตามกฎหมาย ระบบที่ใช้งานจริงยังต้องมีการตรวจวัดซ้ำ การตรวจสอบสถานะ กฎการดำเนินงาน และการอนุญาตให้ตรวจวัดแต่ละ Endpoint
